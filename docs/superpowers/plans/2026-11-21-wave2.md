# Wave 2 Implementation Plan — Devanagari OCR, retrieval, context-reuse metrics, localised letters, platform tests, matcher fixes

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:test-driven-development. Steps use checkbox syntax. Each stream is implemented in its own git worktree by one agent.

**Goal:** Turn the Phase 4 expansion plan (`docs/planning/phase4-expansion-plan.md`) into code: six independent streams, merged on `wave2/integration`, then one PR to `main`.

**Architecture:** Six streams with **disjoint file ownership** run in parallel. Shared files are append-only or integrator-owned. The integrator (not the streams) wires new harnesses into the evaluation runner and regression gate, regenerates the baseline, runs one combined `pytest`, and merges the handoffs into `PROJECT_CONTEXT.md` and `CHANGELOG.md`.

**Tech Stack:** Python 3.11, FastAPI, SQLAlchemy, pytest, EasyOCR (local cache), Node 20 + tsx for the terminology dump, GitHub Actions, k6, kustomize.

**Spec:** `docs/planning/phase4-expansion-plan.md` (decisions D1-D9, workstreams A-G) and `docs/superpowers/plans/2026-11-18-wave1.md` (conventions this wave inherits).

## Global Constraints
- AGENTS.md rules apply: zero document retention (ADR-003/010), `GROQ_MODEL` from the environment, naming (`kadi_*`, `billnyay_*`, ... table prefixes, lowercase package dirs), no raw `print()` in package code, Alembic revision for any schema change, **single API process (ADR-019)**.
- **No fabrication.** No metric is claimed that was not measured; every report says synthetic versus real and n. No accuracy figure for Devanagari OCR or LLM output is claimed without a reference transcription or a live run.
- **Network:** no downloads, no calls to Groq, **never disable TLS verification**, no live network in tests (the `network_guard` fixture stays on). EasyOCR weights are already cached (`EASYOCR_MODULE_PATH`); do not fetch more.
- **No PHI in telemetry or logs** (counts and fingerprints only). Hindi/Marathi text written by an engineer or model is **UNREVIEWED**: mark it `NEEDS NATIVE-SPEAKER QA` in code and docs.
- **Test-first.** Run the whole suite in **one** `pytest` invocation (`PYTHONPATH` = the worktree's `apps/api` plus each `packages/*` directory; confirm `python -c "import kadi; print(kadi.__file__)"` resolves inside the worktree). Baseline on this branch: **1411 passed, 9 skipped**. Also run `ruff check apps/api packages scripts --select=E9,F63,F7,F82`, `PYTHONPATH=apps/api lint-imports` (5 contracts) and `python scripts/ci_guardrails.py`.
- Streams do **not** edit: `PROJECT_CONTEXT.md`, `CHANGELOG.md`, `apps/api/app/evaluation/runner.py`, `regression.py`, `baseline/phase4_baseline.json`, `scripts/evaluate_phase4.py`, `.github/workflows/ci.yml` (stream D only). Shared append-only files: `apps/api/requirements.txt`, `.env.example`, `docs/configuration/environment-variables.md`.
- Each stream writes `docs/superpowers/handoff/wave2-<stream>.md` (what shipped, decisions, env vars, **exact wiring the integrator must add**, unverified items) and commits in logical commits ending with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus
- A Devanagari page whose text layer is corrupted must be routed to OCR, never trusted (and a clean English PDF must keep its text path).
- The default OCR language setting must keep today's behaviour (`en` only); turning on `hi,mr,en` must not change results for English documents.
- Retrieval must return "not found" rather than a made-up citation, and must never decide eligibility.
- Per-case indexes must be in memory and expunged with the case (BYOD).
- A fix to the BillNyay matcher must not turn a previously correct mapping into a wrong one (regression-tested against the BMA dataset).
- Localised letters must still satisfy the grounding and completeness harnesses (no new ungrounded claims).

## Stream tasks (each ends with a green combined test run and a handoff file)

### A — Devanagari OCR
- [ ] `assess_text_layer(text: str) -> TextLayerAssessment` (`pdf_text_quality.py`): fields `devanagari_ratio`, `legacy_font_signature`, `known_word_ratio`, `verdict` in `{"clean","corrupted","not_devanagari"}`. Tests: the real corrupted samples quoted in `data/raw/devanagari_public_docs/README.md` classify `corrupted`; clean Marathi and English text do not.
- [ ] `OCR_LANGUAGES` setting (default `"en"`); reader cache keyed by the language tuple; unknown codes rejected. Test: default builds `["en"]`; `hi,mr,en` builds that tuple (fake reader, no model).
- [ ] PDF path: a page whose verdict is `corrupted` is rasterised and OCR'd; clean pages keep the text path; the decision is recorded in the extraction warnings (count only).
- [ ] `scripts/devanagari_ocr_baseline.py`: rasterise the downloaded PDFs, run `["en"]` and `["hi","mr","en"]`, write JSON (segments, confidence histogram, latency, peak memory) outside git. **No WER/CER** (no reference yet).

### B — Retrieval
- [ ] `kadi.retrieval`: `chunk_document(text, source, page) -> list[Chunk]`, `Bm25Index.add/search(query, k) -> list[Hit]` with `Hit(source, page, quote, score)`; pure Python, deterministic; `search` returns `[]` (never a guess) below a score floor.
- [ ] Per-case in-memory index with `purge()`; test that nothing is written to disk.
- [ ] `schemesetu.ranking.rank_schemes(profile, results) -> list[RankedScheme]` (eligibility status first, relevance second, always `provisional=True`); eligibility logic unchanged (existing tests pass untouched).
- [ ] `schemesetu.citations`: `verify_citation(sentence, hit) -> CitationVerdict` (figures, scheme names, thresholds must match the cited span) and `explain_i18n` hi/mr templates over the deterministic trace, marked UNREVIEWED.
- [ ] `apps/api/app/evaluation/retrieval.py`: `evaluate_retrieval(gold, searcher)` -> Recall@k, MRR, precision/recall, PCRA; datasets are **hand-labelled on clean in-repo text** (the real PDFs' text layers are corrupted and unusable); report as synthetic.

### C — Context reuse (#112)
- [ ] `ContextRequestEvent` and counters `arogya_context_requests_total{module,outcome}` (`reused|fresh`) through the existing telemetry API, bounded labels.
- [ ] Instrument where modules read case context; add a setting that disables reuse to measure the baseline.
- [ ] `evaluate_context_reuse(scenarios)` -> CRR and DPR on demo scenarios A-E; hand-computed unit tests; report with n.

### D — Localised letters, injection v2, terminology CI
- [ ] `bimanyay.catalogue`: reviewed-structure message catalogue for the 5 denial categories x en/hi/mr (grounds, violation summaries, statute names); `draft_*` use it so hi/mr letters have **no English grounds text**; English output byte-identical to today. Test: the terminology audit's Latin-word count for the letters drops to the allow-list only; `appeal` and `grounding` harness results do not regress.
- [ ] Confusables folding in `kadi.injection._matching_view` (Cyrillic/Greek lookalikes -> Latin) plus a hi/mr/Hinglish **red-team corpus** (>= 100 attacks, >= 100 benign look-alikes); tests report detection and false-positive rates as measured, not as targets.
- [ ] `ci.yml`: a `terminology-audit` job (Node 20, report-only upload of the generated worksheet); `ci-gate` must not require it.

### E — Platform
- [ ] `tests/load/*.js` k6 scripts (health, case create, upload, stream) with thresholds; `load-test.yml` is `workflow_dispatch` only. **Not run in CI here.**
- [ ] `tests/chaos/`: pytest fault-injection (DB unavailable, LLM timeouts, OCR crash, disk full) asserting readiness and error payloads; failures found are reported in the handoff.
- [ ] `infrastructure/policy/` OPA/Kyverno policies with YAML-parsing policy tests in the style of `tests/infrastructure`; `supply-chain.yml` (SBOM + keyless cosign) on release tags only.
- [ ] `ADR-025` **Proposed**: job queue superseding the "no broker" decision in ADR-019; no implementation.

### F — Matcher fixes
- [ ] Whole-word matching in `_match_cghs_key` (fix `ppe` in "appendectomy", `icu` in "particular") plus a small reviewed synonym table (USG/sonography, X ray, PTCA, haemodialysis); test: every BMA row that was correct stays correct.
- [ ] `line_items`: tolerate `Name - 400` and trailing text after the amount; `Total - N` is a summary line.
- [ ] DawaCheck: a combination product maps to a combination entry or is refused; no phonetic match skips the dosage rule.
- [ ] Re-run `scripts/evaluate_phase4.py`; the handoff reports before/after for BMA, PEA, anomaly and DawaCheck.
