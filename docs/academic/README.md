## 2. Document Descriptions & Usage Guide

### 2.1 Presentations (`presentations/`)
- **`AI-Assisted Healthcare Decision Support Platform.pptx`**: Comprehensive presentation deck covering problem statement, system architecture, Kadi intelligence layer, multi-agent reasoning, and experimental evaluation.
- **`ArogyaRakshak_Deck.pptx`**: Concise summary deck tailored for project reviews and seminar milestones.
- **`Script for PPT.docx`**: Step-by-step presentation delivery script and speaker notes matched to slide numbers.

### 2.2 Viva & Defense (`viva-and-defense/`)
- **`Viva QNA.docx`**: Curated Q&A repository covering theoretical foundations, trade-offs (e.g., BYOD zero document retention vs persistent storage, Groq LLM selection, FAISS vs pgvector), and failure mode defenses.
- **`Evaluation Metrics.docx`**: Formal definitions and formulas for project evaluation metrics:
  - **Price Extraction Accuracy (PEA)**
  - **Benchmark Mapping Accuracy (BMA)**
  - **Cross-Lingual Matching Accuracy (CRMA)**
  - **Word Error Rate / Character Error Rate (WER/CER)**
- **`ArogyaRakshak_Challenges_Answered.pdf`**: Answers to technical critique points raised during guide evaluations.

### 2.3 Research & Literature (`research-and-literature/`)
- **`ArogyaRakshak_Base_Paper_and_Literature_Review.pdf`**: Deep dive into state-of-the-art healthcare claims auditing, OCR in clinical settings, and RAG architectures.
- **`ArogyaRakshak_Literature_Bank.pdf`**: Annotated bibliography and comparative synthesis of existing research.
- **`ArogyaRakshak_Dataset_Research.pdf`**: Exploration of open government datasets (CGHS rates, NPPA Schedule-I price orders, PMJAY package rates, MJPJAY guidelines).
- **`ArogyaRakshak_Research_Contribution_Note.md` / `.pdf`**: Formal research contribution note isolating the cross-lingual phonetic and semantic entity resolution pipeline in Kadi (prepared for IndiaAI Fellowship framing).
- **`Research Papers Analysis.docx`**: Systematic analysis and critique of related academic publications.
- **`papers/`**: Local repository of 13 academic reference papers cited throughout the project documentation.

### 2.4 Reports (`reports/`)
- **`ArogyaRakshak_Technical_Documentation.md`**: Foundational technical project specification covering architecture, database models, and module specifications.
- **`ArogyaRakshak_Technical_Documentation_v2.pdf`**: Compiled PDF specification of the complete platform design.
