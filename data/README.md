# Data — ArogyaRakshak

This directory will hold ingestion scripts and processed data for the government reference datasets used by each module:

| Module | Data Source | Status |
|---|---|---|
| BillNyay | CGHS rate schedules | Not yet ingested |
| SchemeSetu | PMJAY (national) + MJPJAY (Maharashtra) eligibility rules, empanelled hospital lists | Not yet ingested |
| DawaCheck | NPPA Schedule-I ceiling price list (~800–900 formulations) | Not yet ingested |
| Kadi | Labeled entity-pair dataset for entity resolution tuning | Not yet created |

Ingestion work is tracked in [Task Backlog Phase 1](../docs/ArogyaRakshak_Task_Backlog.md).
