# Pins EasyOCR's transitive torch/torchvision dependency to the CPU-only build.
#
# packages/kadi/pyproject.toml declares easyocr, which requires torch (unpinned) and
# torchvision>=0.5 but does not pin a CPU/GPU variant. Left unconstrained, pip resolves
# PyPI's default Linux wheel, which is CUDA-enabled: torch alone pulls 11 nvidia-*-cu12
# packages plus triton (~2.8 GB combined) even though
# packages/kadi/kadi/ocr/ocr_parser.py always initializes EasyOCR with gpu=False — no
# code path anywhere uses a GPU. That bloat is what exhausted CI runner disk during the
# Docker build (see GitHub issue #141).
#
# The CPU-only build below (from PyTorch's own wheel index) has zero nvidia-*/triton
# dependencies and totals ~197 MB. torch/torchvision must stay a matched release pair —
# check https://github.com/pytorch/vision#installation before bumping either line.
--extra-index-url https://download.pytorch.org/whl/cpu

torch==2.4.1+cpu
torchvision==0.19.1+cpu
